# Deployment Handoff: G4 Browser Security Headers & CSP Foundation

## Overview
This document specifies the browser security headers, Content Security Policy foundation (`Content-Security-Policy-Report-Only`), verification checklist, and field-testing instructions for Batch 3 G4 (`feat/g4-browser-security-headers-csp`).

**CRITICAL POLICY**:
CSP is intentionally deployed in **Report-Only** mode (`Content-Security-Policy-Report-Only`). It must NOT be enforced (`Content-Security-Policy`) until manual QA across all target platforms confirms zero unintended policy violations.

---

## 1. Header Topology & Coverage

| Response Class | Header Directives | Mechanism |
| :--- | :--- | :--- |
| **Static HTML & Assets** (`/*`) | `X-Content-Type-Options: nosniff`<br>`Referrer-Policy: strict-origin-when-cross-origin`<br>`X-Frame-Options: DENY`<br>`Permissions-Policy: ...`<br>`Content-Security-Policy-Report-Only: ...` | `web/public/_headers` (copied to `dist/_headers`) |
| **Application Assets** (`/assets/*`) | `Cache-Control: public, max-age=31536000, immutable` | `web/public/_headers` |
| **PWA Lifecycle Files** (`/index.html`, `/sw.js`, `/manifest.webmanifest`) | `Cache-Control: no-cache` | `web/public/_headers` |
| **Cloudflare Pages Functions** (`/api/*`) | `X-Content-Type-Options: nosniff`<br>`Referrer-Policy: strict-origin-when-cross-origin`<br>`X-Frame-Options: DENY`<br>*(Preserves CORS, Cache-Control, Retry-After, Content-Type)* | `web/functions/lib/securityHeaders.ts`<br>`web/functions/_middleware.ts`<br>`web/functions/lib/authCore.ts` |

## 2. Content Security Policy (Report-Only) Specification

```text
default-src 'self';
script-src 'self' https://accounts.google.com https://apis.google.com;
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com https://accounts.google.com;
font-src 'self' data: https://fonts.gstatic.com;
img-src 'self' data: blob: https://*.googleusercontent.com https://accounts.google.com https://ssl.gstatic.com;
connect-src 'self' https://accounts.google.com https://www.googleapis.com ws: wss:;
frame-src https://accounts.google.com;
frame-ancestors 'none';
object-src 'none';
base-uri 'self';
form-action 'self';
worker-src 'self' blob:;
manifest-src 'self'
```

### Directive Justifications & Compatibility Guards:
- **`'unsafe-inline'` in `style-src`**: Required for dynamic Tailwind/React runtime styles (e.g., inline CSS variables for typography/custom palette theming and Stage Mode settings).
- **No `'unsafe-eval'`**: Independently validated as unnecessary across client modules and dependencies.
- **`data:` in `img-src`**: Required for QR code SVG Data URIs generated by `src/utils/qrCode.ts`.
- **`https://accounts.google.com` & `https://apis.google.com`**: Required for Google Identity Services (GIS) client script, One-Tap iframe, and authentication flows.
- **`https://*.googleusercontent.com`**: Required for authenticated user profile avatars rendered in Header and User Management.
- **`ws:` & `wss:` in `connect-src`**: Required for BandSync local network Leader-Follower teleprompter synchronization (`ws://${leaderIp}:8765`).
- **`frame-ancestors 'none'` & `X-Frame-Options: DENY`**: Eliminates clickjacking risks by disallowing third-party framing of GTAR.

## 3. Permissions-Policy Specification

```text
camera=(self),
clipboard-read=(self),
clipboard-write=(self),
fullscreen=(self),
screen-wake-lock=(self),
geolocation=(),
microphone=(),
payment=(),
usb=(),
interest-cohort=()
```

- **Allowed (`(self)`)**: Camera (QR code scanner), Clipboard read/write (copy/paste chords, setlist share links, backup JSON), Fullscreen (Stage presentation mode), Screen Wake Lock (preventing device sleep during live performances).
- **Restricted (`()`)**: Geolocation, Microphone (audio is output-only via Web Audio API for metronome), Payment, USB, and FLoC tracking.

## 4. Cross-Origin Policy Evaluation
- **Cross-Origin-Opener-Policy (COOP)**: Unset. Enforcing `same-origin` breaks Google Identity popup and GIS One-Tap opener context, as well as desktop StageCast multi-window popups (`window.open`).
- **Cross-Origin-Embedder-Policy (COEP)**: Unset. Enforcing `require-corp` breaks loading external Google profile avatars (`*.googleusercontent.com`) and Google Fonts because upstream endpoints do not send CORP headers.
- **Cross-Origin-Resource-Policy (CORP)**: Unset on API routes. Prevents conflict with existing `Access-Control-Allow-Origin: *`.

## 5. DEV Browser Verification Checklist

Perform these tests on a live Cloudflare Pages preview/dev deployment:

### A. Desktop Browsers (Chrome, Edge, Firefox, Safari)
- [ ] **Console Inspection**: Open DevTools Console; confirm NO `[Report Only]` CSP violation warnings during standard navigation.
- [ ] **Google Sign-In**: Authenticate via Google Identity Services button and verify avatar displays correctly from `googleusercontent.com`.
- [ ] **Stage Mode Teleprompter**:
  - [ ] Fullscreen mode toggles successfully.
  - [ ] Screen Wake Lock acquires without Permissions-Policy rejection.
- [ ] **Desktop StageCast**: Open presentation pop-up window (`window.open`) and confirm two-way communication functions.
- [ ] **BandSync**: Connect to a local stage leader over WebSocket (`ws://` or `wss://`); confirm connect-src does not block the socket.
- [ ] **Clipboard Actions**: Copy setlist share URL and export JSON to clipboard; paste raw ChordPro text in Editor.

### B. Mobile Browsers & iOS PWA (iPhone / iPad Safari)
- [ ] **Camera QR Flow**: Open QR camera scanner; confirm camera permission prompt appears and camera feed functions.
- [ ] **PWA Installation**: Install GTAR to Home Screen; confirm manifest loads and app launches in standalone display mode.
- [ ] **PWA Offline Operation**: Disconnect network; verify cached application shell, offline songs, and local editing operate without errors.
- [ ] **PWA Update Lifecycle**: Deploy a new commit to DEV; verify service worker fetches updates on background navigation and triggers prompt.

## 6. Live Edge Behaviors Requiring Deployment
The following behaviors cannot be verified in local offline unit tests and require verification on the Cloudflare Pages DEV deployment:
1. **Actual Edge Response Headers**: Verification that Cloudflare's edge proxy respects `_headers` without stripping custom security headers.
2. **Real-world CSP Reporting**: Verification that Google Identity Services One-Tap prompt does not trigger unexpected telemetry warnings on Safari / WebKit.
3. **iOS Standalone PWA Camera**: Verification of iOS WebKit camera permissions inside standalone Home Screen web app mode.

---

## 7. Promotion Gate
**DO NOT switch from `Content-Security-Policy-Report-Only` to `Content-Security-Policy` (enforced)** until:
1. All items in the DEV Browser Verification Checklist pass on physical devices.
2. At least 7 days of live DEV/Staging traffic produce zero CSP violation reports in browser consoles.
